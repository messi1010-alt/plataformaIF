# plataformaIF

NEXIF — Conecte-se ao seu futuro

Uma plataforma educacional que conecta conhecimento, tecnologia e oportunidades.

A NEXIF é um projeto independente desenvolvido para apoiar estudantes na preparação para o Exame de Seleção do Instituto Federal do Rio Grande do Norte (IFRN), reunindo conteúdos, materiais de estudo e recursos de revisão em um só lugar.

Acesse a plataforma: https://messi1010-alt.github.io/plataformaIF/

Repositório: https://github.com/messi1010-alt/plataformaIF

---

Sobre o projeto

A NEXIF nasceu com o propósito de tornar a preparação para o ingresso no IFRN mais acessível, organizada e prática.

O projeto utiliza a tecnologia como ferramenta de apoio à educação, oferecendo um ambiente digital no qual os estudantes podem encontrar conteúdos, praticar questões e consultar informações relacionadas ao processo seletivo e aos cursos técnicos.

O nome NEXIF combina a ideia de nexo, que representa conexão, com a sigla IF, referência aos Institutos Federais. Essa identidade expressa a proposta de conectar estudantes ao conhecimento e a novas oportunidades acadêmicas.

Objetivos

- Centralizar materiais de estudo em uma plataforma digital.
- Apoiar a preparação para o Exame de Seleção do IFRN.
- Facilitar a revisão dos conteúdos escolares.
- Incentivar a prática por meio de questões e atividades.
- Reunir informações úteis sobre cursos técnicos e processos seletivos.
- Aplicar conhecimentos de desenvolvimento web na construção de uma solução educacional.
- Expandir continuamente os recursos e melhorar a experiência dos estudantes.

Recursos da plataforma

A NEXIF reúne áreas de estudo e ferramentas voltadas à preparação acadêmica, conforme os recursos disponíveis no site.

- Português: conteúdos de língua portuguesa e revisão.
- Matemática: materiais de estudo e preparação.
- Redação: orientações para desenvolver a escrita e a argumentação.
- Questões: exercícios para praticar os conteúdos estudados.
- Simulados e quiz: recursos de prática e revisão, conforme disponíveis.
- Exame de Seleção: informações e orientações relacionadas ao processo seletivo.
- Temas anteriores: consulta a temas de redação de edições anteriores, quando disponíveis.
- Cursos técnicos: informações e materiais relacionados aos cursos e campi contemplados pelo projeto.

A disponibilidade e a atualização dos recursos podem variar. Consulte o site para verificar os conteúdos publicados.

Tecnologias

O projeto utiliza tecnologias de desenvolvimento web, conforme implementadas no código-fonte:

- HTML5: estruturação das páginas.
- CSS3: estilização e apresentação visual.
- JavaScript: interatividade e funcionalidades.
- GitHub Pages: hospedagem da versão pública da plataforma.

Como acessar

Não é necessário instalar programas para acessar a versão publicada.

1. Entre em https://messi1010-alt.github.io/plataformaIF/.
2. Escolha a área de estudo desejada.
3. Consulte os materiais disponíveis.
4. Utilize os recursos de prática e revisão oferecidos pela plataforma.

Executar localmente

Para obter uma cópia do projeto e executá-la localmente:

1. Clone o repositório:
   
   git clone https://github.com/messi1010-alt/plataformaIF.git

2. Acesse a pasta do projeto:
   
   cd plataformaIF

3. Abra o arquivo "index.html" em um navegador.

Você também pode abrir a pasta em um editor de código, como o Visual Studio Code, para estudar e modificar os arquivos.

Organização do projeto

A organização exata depende dos arquivos presentes no repositório. De forma geral, o projeto utiliza páginas web para separar as áreas de conteúdo e arquivos de estilo e scripts, quando necessários.

- "index.html": página inicial.
- Páginas HTML: páginas de conteúdo e funcionalidades.
- Arquivos CSS: estilos e apresentação visual.
- Arquivos JavaScript: interações e comportamentos.
- "README.md": documentação do projeto.

Consulte o repositório para verificar a estrutura atual dos arquivos.

Melhorias futuras

A NEXIF pode evoluir continuamente por meio de melhorias como:

- Ampliação e revisão dos materiais de estudo.
- Expansão do acervo de questões e simulados.
- Aprimoramento da navegação em celulares e computadores.
- Melhorias de acessibilidade e usabilidade.

- Expansão do conteúdo para outros processos seletivos e instituições de ensino.

Esses itens representam possibilidades de desenvolvimento e não significam que todas essas funcionalidades já estejam implementadas.

Independência do projeto

A NEXIF é uma iniciativa educacional independente e não representa oficialmente o Instituto Federal do Rio Grande do Norte (IFRN) nem qualquer outra instituição de ensino.

Para informações oficiais sobre inscrições, calendários, editais, resultados e regras dos processos seletivos, consulte os canais institucionais responsáveis.
